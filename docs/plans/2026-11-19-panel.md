# Panel — Uygulama Planı
> REQUIRED SUB-SKILL: superpowers:executing-plans

**Goal:** Şifreli tek panel: veri.json düzenleme + ziyaret/tıklama istatistiği.
**Architecture:** Bio sayfası veri.json'dan render eder (yedek: gömülü içerik). Cloudflare Worker `maksat114-panel`: `/o` sayaç (D1), `/panel` arayüz, `/api/*` (giriş, istatistik, veri oku/yaz → GitHub Contents API).
**Tech Stack:** Düz HTML/JS, Cloudflare Workers + D1, wrangler, node:test.
**Spec:** docs/specs/2026-11-19-panel-design.md

## Global Constraints
- IP saklanmaz, çerez yalnız panel oturumu (HttpOnly, Secure, SameSite=Strict).
- Sayaç hatası bio sayfasını bozmaz (sendBeacon, try/catch).
- Secrets: PANEL_SIFRE, OTURUM_ANAHTAR, GH_TOKEN — hiçbir dosyaya/sohbete yazılmaz.
- Repo: maksat114bursa/maksat114bursa.github.io, dosya veri.json, dal main.

## Review Focus
1. Bozuk veri.json kaydı → sayfa gömülü içerikle açılmalı; panel kaydetmeden önce doğrular (zorunlu alanlar, https linkler).
2. Eşzamanlı kayıt (iki kişi) → GitHub sha çakışması 409 → panel "sayfa başka yerde değişti, yenile" der.
3. Kaba kuvvet giriş → 10 yanlış/15 dk kilit.
4. Sayaç spam → olay adı beyaz liste, uzunluk sınırı.
5. Instagram uygulama içi tarayıcı → sendBeacon yoksa fetch keepalive.

### Task 1: veri.json + render (sayfa)
- Create `veri.json`; modify `index.html`: bölümleri `veri`den basan `ciz(veri)`; her linke `data-olay`.
- Test: `araclar/kontrol.mjs` genişlet (veri.json şeması + linkler) → PASS; headless ekran görüntüsü öncekiyle aynı.

### Task 2: Worker (sayaç + API)
- Create `panel/src/index.js`, `panel/wrangler.toml`, `panel/schema.sql`, `panel/test/*.test.mjs`.
- Saf fonksiyonlar test edilir: `cihaz(ua)`, `kaynak(ua, ref)`, `veriDogrula(v)`, `oturumImzala/Dogrula`.
- `node --test panel/test` → PASS.

### Task 3: Panel arayüzü
- `panel/src/panel.html` (Worker içine gömülür): giriş, İstatistik sekmesi, Düzenle sekmesi.
- Yerel `wrangler dev` ile deneme + ekran görüntüsü.

### Task 4: Yayın (kullanıcı Cloudflare hesabı açtıktan sonra)
- wrangler login, D1 oluştur, secrets, deploy; sayfaya sayaç adresi; push; uçtan uca: ziyaret → panelde görünür; panelden kaydet → canlıda değişir.
